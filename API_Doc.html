School Portal API Documentation

RESTful APIs to manage schools, users, classes, subjects, and more.
Example base URL: https://your-domain/api/

Student APIs

MethodEndpointDescription
POST/student/registerRegister a new student
POST/student/loginStudent login
GET/student/:schoolIdList all students of a school
GET/student/detail/:idGet student details by ID
DELETE/student/:idDelete student by ID
DELETE/student/all/:schoolIdDelete all students by school
DELETE/student/byclass/:idDelete students by class
PATCH/student/:idUpdate a student's info
PATCH/student/result/:idAdd/update student exam result
PATCH/student/attendance/:idAdd/update student attendance
PATCH/student/clear/bySubject/:idClear attendance by subject
PATCH/student/clear/all/:idClear all attendance by school
PATCH/student/remove/bySubject/:idRemove attendance by subject
PATCH/student/remove/all/:idRemove all attendance
