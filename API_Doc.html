Data Models

This section describes all database schemas, their properties, and data types used throughout the API.

Student Model

Collection: student

Description: Represents a student enrolled in a school with personal information, academic records, and attendance tracking.

name (String) REQUIRED
Full name of the student
rollNum (String) REQUIRED
Unique roll number for the student (used for login)
password (String) REQUIRED
Hashed password for authentication
sclassName (ObjectId → sclass) REQUIRED
Reference to the class the student belongs to
school (ObjectId → admin) REQUIRED
Reference to the school/admin
role (String) Default: "Student"
User role identifier
email (String) Optional
Student's email address
phone (String) Optional
Contact phone number
address (String) Optional
Residential address
profilePicture (String) Optional
URL to profile picture
dateOfBirth (Date) Optional
Student's date of birth
examResult (Array of Objects) Optional
Array of exam results with subject references and marks obtained
• subName (ObjectId → subject): Subject reference
• marksObtained (Number): Marks scored (default: 0)
attendance (Array of Objects) Optional
Attendance records for the student
• date (Date, required): Date of attendance
• status (String, required): "Present" or "Absent"
• subName (ObjectId → subject, required): Subject reference
notificationPreferences (Object) Optional
Notification settings
• email (Boolean, default: true)
• sms (Boolean, default: false)

Teacher Model

Collection: teacher

Description: Represents a teacher with assigned subjects, classes, and attendance tracking capabilities.

name (String) REQUIRED
Full name of the teacher
email (String, unique) REQUIRED
Unique email address (used for login)
password (String) REQUIRED
Hashed password for authentication
role (String) Default: "Teacher"
User role identifier
school (ObjectId → admin) REQUIRED
Reference to the school/admin
teachSubject (ObjectId → subject) Optional
Subject assigned to the teacher
teachSclass (ObjectId → sclass) REQUIRED
Class assigned to the teacher
attendance (Array of Objects) Optional
Teacher's attendance records
• date (Date, required): Date of attendance
• presentCount (String): Number of students present
• absentCount (String): Number of students absent
phone (String) Optional
Contact phone number
address (String) Optional
Residential address
profilePicture (String) Optional
URL to profile picture
dateOfBirth (Date) Optional
Teacher's date of birth
notificationPreferences (Object) Optional
Notification settings (same structure as Student)
timestamps (Auto-generated)
Automatically adds createdAt and updatedAt fields

Admin Model

Collection: admin

Description: Represents a school administrator with full management capabilities.

name (String) REQUIRED
Full name of the administrator
email (String, unique) REQUIRED
Unique email address (used for login)
password (String) REQUIRED
Hashed password for authentication
role (String) Default: "Admin"
User role identifier
schoolName (String, unique) REQUIRED
Unique name of the school
phone, address, profilePicture, dateOfBirth, notificationPreferences
Same as Student/Teacher models

Class (sclass) Model

Collection: sclass

Description: Represents a class/grade in the school system.

sclassName (String) REQUIRED
Name of the class (e.g., "Grade 10A", "Class 5B")
school (ObjectId → admin) REQUIRED
Reference to the school/admin
timestamps (Auto-generated)
Automatically adds createdAt and updatedAt fields

Subject Model

Collection: subject

Description: Represents a subject taught in a specific class with teacher assignment.

subName (String) REQUIRED
Name of the subject (e.g., "Mathematics", "English")
subCode (String) REQUIRED
Unique subject code (e.g., "MATH101")
sessions (String) REQUIRED
Number of sessions/periods per week
sclassName (ObjectId → sclass) REQUIRED
Reference to the class this subject belongs to
school (ObjectId → admin) Optional
Reference to the school/admin
teacher (ObjectId → teacher) Optional
Reference to the assigned teacher
timestamps (Auto-generated)
Automatically adds createdAt and updatedAt fields

Notice Model

Collection: notice

Description: Represents announcements/notices created by admin with read tracking for students and teachers.

title (String) REQUIRED
Title of the notice
details (String) REQUIRED
Detailed content of the notice
date (Date) REQUIRED
Date when the notice was created
school (ObjectId → admin) Optional
Reference to the school/admin
readBy (Array of Objects) Optional
Tracks which users have read the notice
• userId (ObjectId): Reference to student or teacher
• userType (String): "student" or "teacher"
• readAt (Date, default: now): Timestamp when marked as read
timestamps (Auto-generated)
Automatically adds createdAt and updatedAt fields

Complain Model

Collection: complain

Description: Represents complaints submitted by students or teachers with status tracking.

user (ObjectId → student) REQUIRED
Reference to the student who created the complaint (can also be teacher)
date (Date) REQUIRED
Date when the complaint was submitted
complaint (String) REQUIRED
Detailed description of the complaint
school (ObjectId → admin) REQUIRED
Reference to the school/admin
status (String, enum) Default: "pending"
Current status of the complaint: "pending" or "resolved"
timestamps (Auto-generated)
Automatically adds createdAt and updatedAt fields

Student APIs

POST /student/register

Description: Register a new student in the system

ParameterTypeRequiredDescription
nameStringYesFull name of the student
rollNumStringYesUnique roll number (used for login)
passwordStringYesPassword for authentication
sclassNameObjectIdYesClass ID the student belongs to
schoolObjectIdYesSchool/Admin ID
emailStringNoStudent's email address
phoneStringNoContact phone number
addressStringNoResidential address

Response: Returns the created student object with all fields including generated _id

POST /student/login

Description: Authenticate a student and return their details

ParameterTypeRequiredDescription
rollNumStringYesStudent's roll number
passwordStringYesStudent's password

Response: Returns student object with populated class and school details, or error message if credentials are invalid

GET /student/:schoolId

Description: List all students belonging to a specific school

ParameterTypeRequiredDescription
schoolIdObjectId (URL param)YesSchool/Admin ID

Response: Returns array of student objects with populated class names, or message if no students found

GET /student/detail/:id

Description: Get detailed information about a specific student

ParameterTypeRequiredDescription
idObjectId (URL param)YesStudent ID

Response: Returns student object with populated class, school, and exam results with subject details

PATCH /student/result/:id

Description: Add or update exam results for a student

ParameterTypeRequiredDescription
idObjectId (URL param)YesStudent ID
subNameObjectIdYesSubject ID
marksObtainedNumberYesMarks scored in the exam

Response: Returns updated student object with new exam result added

PATCH /student/attendance/:id

Description: Add or update attendance record for a student

ParameterTypeRequiredDescription
idObjectId (URL param)YesStudent ID
dateDateYesDate of attendance
statusStringYes"Present" or "Absent"
subNameObjectIdYesSubject ID

Response: Returns updated student object with new attendance record

MethodEndpointDescription
DELETE/student/:idDelete student by ID
DELETE/student/all/:schoolIdDelete all students by school
DELETE/student/byclass/:idDelete students by class
PATCH/student/:idUpdate student's personal information
PATCH/student/clear/bySubject/:idClear attendance records for a specific subject
PATCH/student/clear/all/:idClear all attendance records
PATCH/student/remove/bySubject/:idRemove attendance by subject
PATCH/student/remove/all/:idRemove all attendance

Notice APIs

POST /notice/

Description: Create a new notice/announcement (Admin only)

ParameterTypeRequiredDescription
titleStringYesTitle of the notice
detailsStringYesDetailed content of the notice
dateDateYesDate of the notice
adminIDObjectIdYesAdmin/School ID (automatically set as school field)

Response: Returns the created notice object

GET /notice/all/:schoolId

Description: Get all notices for a specific school

ParameterTypeRequiredDescription
schoolIdObjectId (URL param)YesSchool/Admin ID

Response: Returns array of notice objects with readBy tracking information

PATCH /notice/read/:id

Description: Mark a notice as read by a student or teacher

ParameterTypeRequiredDescription
idObjectId (URL param)YesNotice ID
userIdObjectIdYesID of the user marking as read
userTypeStringYes"student" or "teacher"

Response: Returns updated notice object with user added to readBy array

PATCH /notice/unread/:id

Description: Unmark a notice as read (remove from readBy list)

ParameterTypeRequiredDescription
idObjectId (URL param)YesNotice ID
userIdObjectIdYesID of the user unmarking as read
userTypeStringYes"student" or "teacher"

Response: Returns updated notice object with user removed from readBy array

MethodEndpointDescription
PATCH/notice/:idUpdate notice content (title, details, date)
DELETE/notice/:idDelete notice by ID
DELETE/notice/all/:schoolIdDelete all notices by school

Complain APIs

POST /complain/

Description: Create a new complaint (Student or Teacher)

ParameterTypeRequiredDescription
userObjectIdYesID of the student or teacher submitting complaint
dateDateYesDate of the complaint
complaintStringYesDetailed description of the complaint
schoolObjectIdYesSchool/Admin ID

Response: Returns the created complaint object with default status "pending"

GET /complain/all/:schoolId

Description: Get all complaints for a specific school (Admin view)

ParameterTypeRequiredDescription
schoolIdObjectId (URL param)YesSchool/Admin ID

Response: Returns array of complaint objects with populated user names and status

GET /complain/user/:id

Description: Get all complaints submitted by a specific user (Student or Teacher view)

ParameterTypeRequiredDescription
idObjectId (URL param)YesUser ID (student or teacher)

Response: Returns array of complaint objects created by the user with current status

PATCH /complain/status/:id

Description: Update the status of a complaint (Admin only)

ParameterTypeRequiredDescription
idObjectId (URL param)YesComplaint ID
statusStringYes"pending" or "resolved"

Response: Returns updated complaint object with new status and populated user name

Error: Returns 400 error if status is not "pending" or "resolved"
